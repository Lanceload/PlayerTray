# PlayerTray

Плеер в трее Windows, который управляет музыкой и видео из любых приложений: браузеров (YouTube, VK, Яндекс Музыка, SoundCloud…), Spotify, Медиаплеера, Telegram и других.

**[Скачать последнюю версию](https://github.com/Lanceload/PlayerTray/releases/latest/download/PlayerTray.exe)** — один файл `PlayerTray.exe`, установка .NET не нужна.

## Возможности

- Значок в трее: щелчок открывает плеер, колёсико меняет громкость, средняя кнопка ставит на паузу, при наведении видна обложка трека
- Выбор источника звука: «Авто» (то, что играет сейчас) или любое приложение и отдельные вкладки браузера
- Обложка, название, перемотка, следующий/предыдущий трек, перемешивание и повтор
- Громкость отдельного приложения и выбор устройства вывода — для всей системы или только для одного приложения
- Стеклянный вид Windows 11 с настраиваемым градиентом или цветами из обложки, визуализатор спектра
- Эквалайзер и усиление через Equalizer APO, история прослушанного
- Расширение для браузера: каждая вкладка с музыкой — отдельный источник
- Автообновление

## Требования

Windows 10 (версия 2004 и новее) или Windows 11, 64 бит. Стекло и акрил — только в Windows 11.

## Первый запуск

Файл не подписан цифровой подписью, поэтому Windows может показать «Система Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае».

Новые значки Windows 11 прячет под стрелку ^ в трее — перетащите значок PlayerTray на панель задач.

Настройки и история хранятся в `%AppData%\PlayerTray`.
